# Norte Studio!!!

Landing page estática para un estudio creativo independiente enfocado en estrategia, identidad y diseño digital.

## Descripción

Este proyecto presenta una propuesta visual moderna y minimalista para una marca llamada "Norte". La web incluye:

- Hero section con mensaje principal y composición visual
- Navegación principal con menú móvil
- Sección de estudio y propuesta de valor
- Selección de proyectos destacados
- Llamada a la acción para contacto
- Reloj analógico dinámico con hora local
- Diseño responsivo para dispositivos móviles y escritorio

## Tecnologías

- HTML5
- CSS3
- JavaScript vanilla
- Fuentes de Google Fonts

## Estructura del proyecto

```text
Myweb/
├── index.html
├── styles.css
├── main.js
├── README.MD
└── .git/
```

### Archivos principales

- `index.html`: estructura y contenido de la landing page.
- `styles.css`: estilos visuales, layout, tipografías y animaciones.
- `main.js`: interacciones del menú, actualización del año actual y reloj analógico.

## Requisitos

Para visualizar el proyecto solo necesitas:

- Un navegador moderno (Chrome, Edge, Firefox, Safari)
- No requiere dependencias ni compilación

## Cómo ejecutarlo

### Opción 1: abrir directamente

Simplemente abre el archivo `index.html` en tu navegador.

### Opción 2: servidor local

Si prefieres servir la página desde un puerto local, ejecuta:

```bash
cd D:\APPS\Github Copilot\Myweb
python -m http.server 8000
```

Luego accede a:

```text
http://localhost:8000
```

## Personalización

Puedes adaptar fácilmente el contenido modificando:

- Títulos y textos en `index.html`
- Colores, tamaños y espaciados en `styles.css`
- Comportamiento del menú y reloj en `main.js`

### Cambios habituales

- Cambiar nombre de la marca
- Modificar correo de contacto
- Ajustar textos de proyectos
- Personalizar paleta de colores y tipografía
